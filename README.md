# Library Management System

A Spring Boot REST API for managing books, members, and transactions in a library.

## Features

- Book Management
- Member Management
- Borrow Book
- Return Book
- Validation & Exception Handling
- REST APIs

## Tech Stack

- Java 21+
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Lombok
- Gradle

## Running Locally

```bash
./gradlew bootRun
```

## API Documentation

Available via Swagger (if configured).
